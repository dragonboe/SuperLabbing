# 🚫 No AI Contribution Policy

We value human experience, authentic testing, and genuine knowledge. 

If you are going to contribute to **SuperLabbing**, we have one strict rule: **Do not use AI.**

## ✍️ Human-Only Contributions
Anyone is welcome to contribute to this project—whether it's adding a new hardware review, updating a software link, or sharing a community resource—as long as the work is your own.

### Why this policy?
*   **Authenticity**: Homelabbing is about personal experimentation. We want your actual results, not an AI's hallucination.
*   **Quality**: Technical guides require human verification. AI often misses the nuances of specific hardware quirks.
*   **Community**: We want to build a resource created by humans, for humans.

### How to contribute (the human way):
1.  Verify the information yourself.
2.  Write from your own experience.
3.  Submit a Pull Request with your original thoughts.

Thank you for keeping this project authentic and human-made!
