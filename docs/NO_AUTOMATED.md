# Contribution Policy

This repository focuses on verified technical information and personal experience. To maintain the quality and reliability of the guides, we adhere to the following policy.

## Human-Generated Content
We strictly prohibit the use of automated text generation for contributions. This project is built on actual testing and documented results.

- **Verification:** All technical claims must be personally verified by the contributor.
- **Authenticity:** We prioritize documentation written from a first-hand technical perspective.
- **Quality Control:** Automated content often contains technical inaccuracies regarding specific hardware and software edge cases that we aim to avoid.

## How to Contribute
If you would like to contribute a hardware review, software recommendation, or technical guide:
1. Ensure the information is current and accurate.
2. Submit a Pull Request with a clear description of your changes.
3. Base your writing on your own technical findings.

Thank you for contributing to a human-made technical resource.
