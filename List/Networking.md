# Networking

Tools for building secure, distributed, and fast virtual networks.

*   **[Netmaker](https://www.netmaker.io/)** - High-speed, secure, and distributed virtual networks.
*   **[Netbird](https://netbird.io/)** - Zero-config VPN that connects devices into a secure mesh network.
*   **[Innernet](https://github.com/tonarino/innernet)** - A private network system that uses WireGuard under the hood.
*   **[Sish](https://github.com/antoniomika/sish)** - HTTP(S)/WS/TCP tunnels and SSH for local developers.
*   **[Iodine](https://github.com/yarrick/iodine)** - Tunnel IPv4 data through a DNS server.
*   **[Tinyproxy](https://tinyproxy.github.io/)** - Light-weight HTTP/HTTPS proxy daemon.
*   **[Cilium](https://cilium.io/)** - eBPF-based networking, security, and observability for Kubernetes.
