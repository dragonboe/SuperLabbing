# Analytics

Web and product analytics tools.

*   **[Matomo](https://matomo.org/)** - The leading open-source alternative to Google Analytics.
*   **[GoAccess](https://goaccess.io/)** - Real-time web log analyzer and interactive viewer.
*   **[OpenPanel](https://openpanel.dev/)** - Next-generation open-source web and product analytics.
*   **[Ackee](https://ackee.electerious.com/)** - Self-hosted, Node.js based analytics tool.
*   **[Umami](https://umami.is/)** - Simple, easy-to-use, self-hosted web analytics.
*   **[Plausible](https://plausible.io/)** - Lightweight and open-source website analytics.
