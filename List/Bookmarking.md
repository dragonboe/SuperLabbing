# Bookmarking

Self-hosted link managers and digital archive tools.

*   **[LinkAce](https://www.linkace.org/)** - A self-hosted archive for your bookmarks.
*   **[Pinry](https://github.com/pinry/pinry)** - The open-source tiling image board system.
*   **[Wallabag](https://wallabag.org/)** - Self-hostable application for saving web pages.
*   **[Espial](https://github.com/m-p-w/espial)** - An open-source, web-based bookmarking server with tagging.
*   **[Shaarli](https://github.com/shaarli/Shaarli)** - The personal, minimalist, super-fast, database-free bookmarking service.
*   **[Shiori](https://github.com/go-shiori/shiori)** - A simple bookmarks manager built with Go.
