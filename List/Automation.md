# Automation

Workflow engines, local automation, and home control systems.

*   **[Home Assistant](https://www.home-assistant.io/)** - Open-source home automation that puts local control and privacy first.
*   **[n8n](https://n8n.io/)** - Fair-code workflow automation with hundreds of integrations.
*   **[DDNS-Go](https://github.com/jeessy2/ddns-go)** - Simple DDNS tool for Aliyun, Tencent Cloud, Cloudflare, and more.
*   **[Organize](https://github.com/tfeldmann/organize)** - The file management automation tool (Python).
*   **[RobotJS](https://robotjs.io/)** - Node.js desktop automation library.
*   **[Node-RED](https://nodered.org/)** - Low-code programming for event-driven applications.
*   **[Huginn](https://github.com/huginn/huginn)** - Create agents that monitor and act on your behalf online.
