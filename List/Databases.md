# Databases

Relational, Graph, and Vector storage engines.

*   **[Bytebase](https://www.bytebase.com/)** - Advanced database DevSecOps solution (GitHub/GitLab for DBs).
*   **[Apache AGE](https://age.apache.org/)** - Graph database extension for PostgreSQL.
*   **[YugabyteDB](https://www.yugabyte.com/)** - Cloud-native distributed SQL database.
*   **[Valkey](https://valkey.io/)** - Distributed key-value database optimized for real-time workloads.
*   **[SQLiteStudio](https://sqlitestudio.pl/)** - Multi-platform SQLite database manager.
*   **[RediSearch](https://redis.io/docs/interact/search-and-query/)** - Query, indexing, and full-text search engine for Redis.
*   **[Redis](https://redis.io/)** - Open-source, in-memory data store used as a database and cache.
*   **[Chat2DB](https://chat2db.ai/)** - Database tool and SQL client with advanced features.
*   **[LevelDB](https://github.com/google/leveldb)** - Fast key-value storage library by Google.
