# 💬 Communications

Platforms for chat, forums, and secure collaboration.

*   **[Zulip](https://zulip.com/)** - Open-source team chat with topic-based threading.
*   **[Mattermost](https://mattermost.com/)** - Secure collaboration platform for technical teams.
*   **[Jitsi Meet](https://jitsi.org/jitsi-meet/)** - Secure, simple, and scalable video conferences.
*   **[Apache Answer](https://answer.apache.org/)** - Q&A platform software for community discussion.
*   **[Synapse](https://github.com/matrix-org/synapse)** - The reference homeserver implementation for the Matrix protocol.
*   **[Zammad](https://zammad.org/)** - Web-based, open-source helpdesk and customer support system.
*   **[Rocket.Chat](https://rocket.chat/)** - The ultimate open-source communications platform.
