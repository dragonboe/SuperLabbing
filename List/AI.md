# 🧠 AI & Machine Learning

Curated list of artificial intelligence tools, local LLMs, and computational environments.

*   **[Ollama](https://ollama.com/)** - The easiest way to get up and running with large language models locally.
*   **[Perplexica](https://github.com/ItzCrazyKBT/Perplexica)** - AI-powered search engine that provides cited answers.
*   **[Leon](https://getleon.ai/)** - Your open-source personal assistant who lives on your server.
*   **[JupyterLab](https://jupyter.org/)** - A web-based interactive development environment for notebooks, code, and data.
*   **[Xinference](https://github.com/xorbitsai/inference)** - Run open-source LLMs as OpenAI-compatible API endpoints.
*   **[LocalAI](https://localai.io/)** - Self-hosted, community-driven, local OpenAI compatible API. 
*   **[Chatpad AI](https://github.com/p_p_p_p_p_p_p/chatpad)** - A beautiful and powerful web client for ChatGPT/LLMs.
*   **[Dify](https://dify.ai/)** - An open-source LLM app development platform.
*   **[DeepLake](https://www.deeplake.ai/)** - The database for AI; store vectors, images, and videos.
