# 🎬 Media Management

Tools for downloading, streaming, and organizing your media collection.

*   **[Radarr](https://radarr.video/)** - Movie collection manager for Usenet and BitTorrent users.
*   **[Sonarr](https://sonarr.tv/)** - Smart TV show PVR developed for Usenet and BitTorrent.
*   **[Ant Media Server](https://antmedia.io/)** - Ultra-low latency video streaming engine.
*   **[Koel](https://koel.dev/)** - Personal music streaming server that uses the modern web.
*   **[Media-Get](https://github.com/foamzou/media-get)** - A powerful tool to get media from various URLs.
*   **[TWMD](https://github.com/mmpx12/twitter-media-downloader)** - CLI/GUI tool for downloading media from Twitter/X.
*   **[Jellyfin](https://jellyfin.org/)** - The free software media system that puts you in control.
