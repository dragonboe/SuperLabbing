# File Management & Backup

Tools for organizing, deduplicating, and backing up your most important data.

*   **[Kopia](https://kopia.io/)** - Cross-platform backup tool with deduplication and encryption.
*   **[Deduplicating Archiver](https://github.com/borgbackup/borg)** - Securely encrypted, deduplicated backups with compression.
*   **[FDUPES](https://github.com/adrianlopezroche/fdupes)** - Program for identifying duplicate files.
*   **[Backupman](https://github.com/miantiao-me/backupman)** - Open-source solution for database backups.
*   **[OpenCloud](https://github.com/open-cloud-project/open-cloud)** - Open-source platform for file sharing and collaboration.
*   **[Photography Toolbox](https://github.com/miantiao-me/pht)** - Cross-platform tool for EXIF reading and batch photo management.
*   **[Rclone](https://rclone.org/)** - "rsync for cloud storage" - supports over 40 cloud storage providers.
