# ☁️ Cloud & Self-Hosted Hosting

Cloud-native solutions and secure hosting foundations.

*   **[Ente](https://ente.io/)** - End-to-end encrypted personal cloud for your photos and data.
*   **[Cryptomator](https://cryptomator.org/)** - Encrypts your data before it is uploaded to any cloud storage.
*   **[Warracker](https://github.com/the-maldridge/warracker)** - Self-hostable warranty tracker for all your hardware.
*   **[PolarDB](https://github.com/alibaba/PolarDB-for-PostgreSQL)** - Cloud-native database based on PostgreSQL.
*   **[Awesome-Tunneling](https://github.com/anderspitman/awesome-tunneling)** - A collection of ngrok/Cloudflare Tunnel alternatives.
*   **[CapRover](https://caprover.com/)** - Automated app deployment and web server manager.
