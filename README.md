## Overview

SuperLabbing is a collection of verified tools and hardware configurations. It focuses on documented performance, efficiency, and real-world utility for home servers.

### Hardware Foundations
Building a lab starts with hardware that matches your workload. Whether it's low-power N100 nodes for 24/7 services or high-performance Ryzen clusters for heavy virtualization, the hardware guides cover efficiency and cost.

### Software Stack
The service directory lists applications for media management, network security, and local automation. Every tool listed is chosen for its stability and community support.

### Networking & Infrastructure
Security is handled through OPNsense, WireGuard, and Zero-Trust architectures. We prioritize setups that avoid unnecessary port forwarding and emphasize internal privacy.
